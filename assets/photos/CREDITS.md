## Share-alike

A CC BY-SA photo carries a share-alike condition. A clip built around one is arguably a derivative, which would put the clip under the same licence. CC BY and public-domain files carry no such condition. If that matters for a given post, restrict the set with `--licenses public-domain,cc-by`.
